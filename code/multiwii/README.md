# MultiWii Flight Control

The aircraft used **MultiWii 2.4** with an **Arduino Mega 2560** as the flight-control architecture.

The completed prototype demonstrated:

- Motor/ESC control
- Stabilized flight
- Radio control
- Radio telemetry
- Payload transportation

The planned GPS waypoint navigation was not completed because the GPS module was non-functional during development. Ultrasonic sensing, compass integration, and Bluetooth integration were also not completed within the project timeframe.

The original MultiWii firmware is not reproduced in this repository. This folder documents its role in the project rather than claiming that the reference Arduino sketch is the flight-control firmware.
